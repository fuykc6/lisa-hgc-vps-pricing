## 线路与延迟：去程绕美国，回程直连

HGC线路的实际路由是去程绕美国、回程直连。路由追踪记录显示，电信去程走NTT、联通去程走Tata，都要先到美国圣何塞再折回香港。落到体验上，大陆方向延迟为：电信约156–176ms，联通约175–221ms，移动约195–210ms。

这个延迟意味着什么，说直白点：看TVB、刷Netflix、挂业务没问题；打游戏、做对延迟敏感的事，别指望它。宣传里的“三网优化”指的是回程直连和整体可达性，把它理解成“低延迟大陆直连”会失望。

速度分两头看。香港本地测速能打满标称带宽：50Mbps套餐实测下载47–49Mbps，150Mbps套餐跑出过143Mbps，本地延迟1–3ms。大陆方向波动比较大——电信节点有跑满的（142–144Mbps），也有只有14–36Mbps的；移动143–159Mbps；联通两份测评都只有10–15Mbps，这个方向明显偏弱。还有个容易被忽略的细节：50Mbps套餐的本地上传实测跑出过494Mbps，上传方向比标称值宽松得多，往外传文件的体验会比下载好。
